# Dominic Soco — Portfolio

A responsive personal portfolio made with plain HTML, CSS, and JavaScript. It uses the supplied portrait and a clean midnight-navy, slate, white, and blue visual theme. No framework, installation, build step, or dependency is required.

## Preview locally

1. Extract `dominic-soco-portfolio.zip`.
2. Open the `dominic-soco-portfolio` folder.
3. Double-click `index.html` to preview it in your browser.
4. For easier editing, open the folder in VS Code and use Live Server.

## Personalize before publishing

This site intentionally avoids inventing personal achievements or credentials. Check and update these items before sharing publicly:

1. **Contact email:** Open `script.js` and replace `YOUR_EMAIL_HERE` with Dominic's real email address.
2. **About section:** Adjust the text in `index.html` to match Dominic's real background, interests, and goals.
3. **Projects:** The three project cards are sample concepts, not claims about completed work. Replace them with actual projects, screenshots, descriptions, technologies, and working links.
4. **Toolkit:** Keep only skills and tools Dominic can confidently describe.
5. **Social links:** Add verified GitHub, LinkedIn, or other profile links if needed.

## Files

- `index.html` — page content and structure
- `styles.css` — visual design and responsive layouts
- `script.js` — mobile navigation, current year, and contact-button behavior
- `assets/dominic-soco.jpg` — portrait supplied for the portfolio
- `assets/favicon.svg` — matching DS favicon

## Publish with GitHub Pages

1. Create a GitHub repository for the portfolio.
2. Upload the files and folders inside this folder (not only the ZIP).
3. In the repository, open **Settings → Pages**.
4. Choose the `main` branch and `/ (root)` folder as the publishing source, then save.
5. Open the URL displayed by GitHub Pages once it has published.
